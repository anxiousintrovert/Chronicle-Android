# Example packages

Copy an individual package directory into your test save's `mods` directory.
Do not copy this enclosing `mods` directory as one package. Restart after install.

| Package | Demonstrates |
|---|---|
| [norune-welcome](norune-welcome) | Map quest plus one-time 50 Gilda Lua reward, using a saved guard |
| [norune-visit](norune-visit) | Quest-only package with no script or currency permission |

The packages use different IDs and can coexist. Both record gameplay state in
saves, so keep their exact versions available for those saves. They contain no
extracted game assets. Quest UI is the manager details pane, not the native journal.

See [manifest format](../../docs/MOD_FORMAT.md) and
[the author walkthrough](../../docs/MOD_AUTHORING.md) before adapting them.
