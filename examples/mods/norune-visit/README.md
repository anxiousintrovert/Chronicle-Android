# Norune Visit Objective

Install this directory at `<save>/mods/norune-visit/` and restart. Enter Norune;
the manager details should show 1/1. There is no Lua script, reward, permission,
dependency, or declared conflict. Progress belongs to the selected save.

Use an independent test save. Disabling and restarting stops tracking, but a
save that records this package requires the enabled version `1.0.0` to load.
